# kaggle-bets

Python・機械学習の経験ゼロから、**コーディングエージェント（Claude Code）を相棒に** Kaggle で機械学習を積み上げていく記録です。

## このリポジトリの方針

今のエンジニアリングでは、ML のコードを一から手で書くことはほとんどありません。コードはエージェントが書けます。
それでも、エージェントに任せきれない部分が残ります。

- **評価の設計**: 交差検証の組み方、リークの見抜き方。エージェントは間違った評価で出た高スコアも、そのまま「改善しました」と報告してくる
- **問題設定と評価指標**: 何を予測し、何で測るか
- **データを見る目**: EDA で「この列は何かおかしい」と気づく力
- **改善が本物かの判断**: スコアの差は実力かノイズか。CV と LB がずれたらどちらを信じるか
- **コードを読む力**: 書けなくても、何をしているかを読み取れること

このリポジトリでは、**エージェントにコードを書かせ、それを読んで、疑って、判断する力**を鍛えることを目標にしています。
各ノートブックは、エージェントが書いたコードに「なぜこう書くか」「ここを間違えると何が起きるか」の解説を添え、自分の理解を確かめながら進めています。

## セットアップ

```bash
uv sync
# Kaggle API トークンを ~/.kaggle/access_token に置いた上で
uv run kaggle competitions download -c titanic -p data/titanic
unzip data/titanic/titanic.zip -d data/titanic && rm data/titanic/titanic.zip
```

コンペのデータは再配布できないため、リポジトリには含めていません。
